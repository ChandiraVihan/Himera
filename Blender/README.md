# Blender Sources

This directory contains editable Blender scenes used during world building.

## K47 exterior graybox

`K47_Exterior_Graybox.blend` is the source scene for the K47 exterior blockout.
Treat it as authoring content: make layout changes here first, then export
approved geometry into Unreal rather than editing an imported result by hand.

Before handoff, verify scale, transforms, object names, collision intent, and
the playable route against the notes in `docs/Architecture.md`.
