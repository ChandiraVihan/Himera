# World Builder Workflow

Use this sequence for the K47 exterior graybox and future environment sources:

1. Block out the layout in the Blender source scene.
2. Check scale and movement space against the first-person setup.
3. Remove hidden or unnecessary geometry before export.
4. Export an approved iteration into the Unreal content tree.
5. Assign collision and materials in Unreal.
6. Test the route, cover, sightlines, and camera presentation in play mode.
7. Record notable integration changes next to the relevant asset documentation.

The Blender file remains the editable source of truth until an Unreal version is
explicitly accepted for gameplay.
